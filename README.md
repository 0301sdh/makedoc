# makedoc

`makedoc`은 코드, 커밋, 작업 기록을 바탕으로 AI가 프로젝트 문서를 만들거나 최신 상태로 갱신하도록 돕는 CLI 도구입니다. Claude Code에 프로젝트 스킬을 설치하고, 문서 작성에 필요한 맥락과 작업 지시를 제공합니다.

## 동작 방식

### 해결하려는 문제

- 프로젝트 문서를 처음부터 만들거나 코드 변경에 맞춰 갱신하는 일은 번거롭습니다.
- 문서 작성에 필요한 프로젝트 구조와 변경 이력을 한 번에 파악하기 어렵습니다.
- 근거가 없는 설명이 문서에 섞이거나, 코드와 문서가 서로 다른 상태로 남기 쉽습니다.

`makedoc`은 프로젝트 파일, `package.json`, Git 커밋, 선택적으로 `.handoff/logs/`의 작업 기록을 모아 AI에 전달합니다. AI는 이를 바탕으로 문서를 작성하고, `makedoc check`로 필수 문서와 일부 누락 항목을 확인합니다.

### 역할 분담

| 주체 | 역할 |
|---|---|
| 프로그램 | Claude Code 스킬 설치, 프로젝트 자료 수집, 문서 누락·일부 형식 검사 |
| AI | 코드를 직접 확인하고 문서를 작성하거나 갱신 |
| 개발자 | 문서와 AI의 판단을 검토 |

## 설치와 Claude Code 연결

Node.js 22 이상이 필요합니다. 저장소에서 빌드해 전역 명령으로 연결합니다.

```sh
git clone https://github.com/0301sdh/makedoc.git
cd makedoc
npm ci
npm run build
npm link
```

`npm link`가 `makedoc` 명령을 전역에 연결합니다. 연결을 해제하려면 `npm uninstall -g makedoc`를 실행합니다.

### 프로젝트에 스킬 설치하기

문서를 만들 프로젝트 폴더에서 실행합니다.

```sh
makedoc init
```

`.claude/skills/makedoc/SKILL.md`에 `/makedoc` 스킬을 설치합니다. 이미 파일이 있으면 덮어쓰지 않습니다. 설치 후 Claude Code에서 `/makedoc`을 호출하거나 프로젝트 문서를 만들어 달라고 요청합니다.

## 기본 작업 흐름

### 1. 스킬 설치하기

대상 프로젝트에서 `makedoc init`을 실행합니다. 스킬 없이 사용하려면 이 단계는 건너뛰고, 아래 `collect` 명령으로 출력한 내용을 AI 대화에 직접 전달하면 됩니다.

### 2. 문서 작성 또는 갱신하기

Claude Code에서 `/makedoc`을 호출합니다. 스킬은 `makedoc collect` 결과를 AI에 전달하고, AI는 관련 코드와 설정을 확인한 뒤 문서 목록의 문서를 작성하거나 갱신합니다.

기본 문서 목록은 다음과 같습니다.

- `README.md`: 프로젝트 소개, 설치, 사용법
- `docs/ARCHITECTURE.md`: 폴더별 역할, 주요 모듈과 데이터 흐름
- `docs/DECISIONS.md`: 되돌리기 어려운 설계 결정과 근거
- `CHANGELOG.md`: 버전별 변경 사항
- `docs/DEVELOPMENT.md`: 개발 환경, 실행, 테스트 방법

기존 문서의 내용을 존중하고, 확인할 근거가 없는 내용은 추측하지 않도록 안내합니다. API 문서와 데이터베이스 ERD는 자동 생성 대상이 아닙니다.

### 3. 문서 검사하기

AI가 문서를 작성한 뒤 대상 프로젝트에서 다음 명령을 실행합니다.

```sh
makedoc check
```

필수 문서의 존재 여부, 아키텍처 문서의 최상위 폴더 설명, 설계 결정의 근거, 개발 문서의 npm 스크립트, 변경 기록의 버전 등을 확인합니다. 문서가 코드 변경보다 오래된 경우 경고도 출력합니다. 이 검사는 문서 내용이 코드와 완전히 일치하는지 판단하지 않으므로 최종 검토는 개발자가 해야 합니다.

### 연결 없이 사용하기

`makedoc init` 없이도 대상 프로젝트에서 아래 명령을 사용할 수 있습니다.

```sh
makedoc collect  # AI에 전달할 자료와 작업 지시 출력
makedoc check    # 문서 누락과 일부 형식 검사
```

출력 내용을 AI 대화에 직접 전달해 문서를 작성하게 할 수 있습니다. `.handoff/logs/YYYY-MM-DD.md`가 있으면 날짜별 작업 기록의 결정과 한 일을 자료에 포함합니다.

## 명령어

| 명령어 | 하는 일 |
|---|---|
| `makedoc init` | 현재 프로젝트에 Claude Code용 `/makedoc` 스킬을 설치합니다. 기존 스킬은 덮어쓰지 않습니다. |
| `makedoc collect` | AI가 문서를 작성하는 데 필요한 프로젝트 정보와 작업 지시를 출력합니다. |
| `makedoc check` | 필수 문서와 일부 항목을 검사합니다. |
| `makedoc --help` | 명령과 옵션의 사용법을 출력합니다. |
| `makedoc --version` | 현재 버전을 출력합니다. |

모든 명령은 작업 대상 프로젝트 폴더에서 실행합니다. 종료 코드는 `0` 성공, `1` 작업 실패 또는 문서 문제 발견, `2` 잘못된 사용법입니다.
